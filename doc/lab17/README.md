# Результаты ЛР17

Основная команда: `python run_lab17.py`. Она использует готовый тестовый образ
или собирает его в чистом окружении,
запускает полный набор CTest и Python unittest и сохраняет отдельные строки
для каждого теста в `tests.txt`. Сводка и контрольные суммы — в `summary.json`.

При запуске скрипт создаёт временную MongoDB для интеграционных тестов.
Тестовый план и команды: [инструкция](../lab17_run.md).

Проверенный прогон 08.11.2026: 154 из 154 CTest и 296 из 296 Python-тестов
прошли без пропусков.
Готовый отчёт: [PDF](../report_lab17.pdf), [исходник](../report_lab17.tex).
