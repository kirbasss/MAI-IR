# ЛР13: результаты TF-IDF

Корпус: 478 833 документа, 2 545 616 терминов в двух пространствах.
Построение норм по 335 548 564 координатам заняло 51,140 с, включая проверку
исходных индексов (один запуск). Дополнительный размер: 7 661 408 байт.

- `build.json` — результат построения.
- `summary.json` — медианы 7 повторений, top-10, SHA-256 и P@5 по заголовкам.
- `queries.jsonl` — 196 измерений после прогрева.
- `tests.txt` — полная регрессия: 144 CTest, 286 Python, 6 MongoDB-проверок пропущены.
- `query_rows.tex` — таблица отчёта по словоформам.
- `web_check.json` — HTTP-проверка настоящего C++-поиска: TF-IDF в обоих
  пространствах и прежний фразовый поиск, все ответы HTTP 200.

`doom eternal`: 9 170 кандидатов, медиана TF-IDF 5,982 мс против 0,892 мс
OR/ID. Первый результат — «Doom Eternal - Мнение», score 0,812775.
`god of war`: 228 464 кандидата, 135,160 мс против 15,757 мс.
Это дополнительная работа ранжирования, а не ускорение булева поиска.

На трёх иллюстративных запросах P@5 видимого соответствия заголовков теме:
AND/ID — 0,4 / 0,8 / 0,6; TF-IDF — 1,0 / 1,0 / 1,0.
Время в таблице отчёта сопоставлено с OR/ID на одинаковых кандидатах.
Веб-скриншоты `doc/img/codes_bool.png` и `doc/img/codes_tfidf.png` показывают
6 результатов для `чит AND коды AND gta` и 18 743 для TF-IDF `чит коды gta`
по леммам.
Разметка помощника по заголовкам сохранена в
`tests/fixtures/lab13_title_judgments.json`; она не оценивает полные документы
и не является представительным независимым бенчмарком.
