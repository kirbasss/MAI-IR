# MAI-IR

Учебный проект по разработке поисковой системы в рамках курса
«Информационный поиск» МАИ.

Корпус документов составляют русскоязычные публикации о компьютерных играх:
новости, статьи, обзоры и блоги игровых изданий.

Проверочная выборка URL находится в `urls.txt`. Подробности первой
лабораторной работы приведены в `doc/report.tex`.
